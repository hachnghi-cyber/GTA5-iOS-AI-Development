# GTA V iOS — AI Lab rules

Follow root AGENTS.md first. Specialist roles are configurations, not 100 independent AI instances.
Use read-only analysis by default; never expose secrets, copy proprietary game assets, or run untrusted IPA contents.
Every conclusion needs evidence. Separate confirmed findings from hypotheses, document risks, reproducible tests, rollback and missing device testing.
No automatic modification, signing, publishing or merging of game builds.
